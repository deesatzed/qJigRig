# Saved-run browser foundation, 2026-11-07

Ran `scripts/verify_saved_run_browser.py` against a temporary loopback catalog with Playwright 1.64.1 and an existing local Chromium executable. The synthetic authored rule returned no for 20 days against a 14-day source. A browser intervention changed the threshold to 30 days; rerunning returned yes. After restarting the service against the same catalog, the browser reopened the original saved result, displayed the 14-day evidence and marked it as requiring rerun against the changed catalog. An actual browser download was saved to a temporary directory; its JSON digest matched the original run ID and the offline structural verifier accepted its source bindings with that supplied digest. At a 390-pixel viewport the document did not overflow horizontally.

The first automation attempt hit the page's content security policy because its wait predicate used string evaluation; replacing it with a function predicate resolved the harness issue. This walkthrough uses deterministic synthetic data and no hosted calls. A matching digest and structural verification are not authentication or proof of decision semantics, and this is not full accessibility, fresh-provider, replay, or workflow acceptance. Temporary databases, downloads and the optional browser dependency are not committed.
